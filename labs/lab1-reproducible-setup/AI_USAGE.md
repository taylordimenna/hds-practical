# AI Usage
### Downloading Conda/Miniforge
I used ChatGPT (GPT-5.6) to help download and set up Conda/Miniforge. It walked me through how to download it and then connect it to vs code to allow me to create the working environment.yml file. 
The prompt I typed into the LLM was:
    
    "How to download conda/miniforge for windows".

It provided me with the link to the correct version of Miniforge for my computer.

ChatGPT also told me to bash 

    conda --version
 
within PowerShell or Git Bash to test whether it worked.

Since "conda 26.7.1" was returned, it was confirmed that Conda/Miniforge was downloaded correctly.

I completed this portion of the lab assignment prior to the second week of classes, where detailed directions were given on how to download this to complete before the second practical.
